# Project → Global Promotion Policy

Project learning is local by default.

A candidate may be proposed for global promotion only when:
- it is not tied to project-specific paths, names, credentials, architecture, or conventions;
- supporting evidence spans multiple independent tasks and preferably multiple repositories;
- it improves a reusable workflow rather than encoding one incident;
- regression tests cover the behavior;
- security impact is reviewed;
- a human or explicit parent decision approves promotion.

The refiner must emit a proposal with evidence and scope. It must not silently rewrite personal/global Skills.
